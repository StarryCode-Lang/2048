# 本地数据与迁移

游戏保持 local-first：无需账号、服务器或遥测。浏览器 localStorage 只保存当前局、偏好和各尺寸最高分，IndexedDB 保存可选的历史冠军回放。

当前局保存信封为 `version: 3`，解析入口是 `app/game/storage.ts`。它会检查棋盘尺寸、每个方块是否为合法 2 的幂、计分器是否为非负安全整数，以及随机种子是否为有效 uint32。旧的无版本或 `version: 2` 存档会在读取时迁移为 v3；损坏数据直接隔离并开始新局，不阻塞游戏。

回放恢复后还会使用 `app/replay/reconstruct.ts` 重放事件，并逐项核对棋盘、分数、步数和随机状态。核对失败时仅丢弃当前回放引用，保留可玩的棋盘。

对局日志当前导出为 `2048-full-replay-v4`。每个 AI 移动在单字节事件的保留位中记录 Search、Expert 或 Adaptive 来源；旧 v1-v3 日志仍可导入并按相同官方随机序列重建。
