# 安全政策

适用基线：`v2.0.0`。线上版本与 `main` 同步；安全修复发布时同步更新 [`../../CHANGELOG.md`](../../CHANGELOG.md) 与 [`../release.md`](../release.md)。

## 支持范围

本项目持续支持 `main` 分支当前在线版本。旧提交不单独维护；已修复的问题会随下一次正式发布上线。

## 报告漏洞

请优先通过 GitHub 的[私密漏洞报告](https://github.com/StarryCode-Lang/2048/security/advisories/new)提交问题，并附上受影响版本、复现步骤、影响范围和建议修复方式。请不要在公开 Issue 中披露可直接利用的细节，也不要访问、修改或保留他人的数据。

维护者会先确认报告，再评估影响、准备修复，并在 GitHub 与在线 Sites 同步发布后协调披露。普通功能缺陷可以使用公开 [Issues](https://github.com/StarryCode-Lang/2048/issues)。
